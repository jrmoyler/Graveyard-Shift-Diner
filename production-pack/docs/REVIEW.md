## Limits

Head/costume parts require final rig/socket assembly. The supplied drawer/plate/door assets do not themselves implement the diner economy.

The offline viewer's JavaScript syntax and file references were checked; a local browser executable was unavailable for live interaction tests. Physical Galaxy A15 validation was not performed. Final game integration must verify seat occlusion, evidence legibility at 2× inspection, mobile memory, sound balance and accessibility settings.
